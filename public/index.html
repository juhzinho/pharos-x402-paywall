The facilitator

This API settles through its own facilitator, served next to it: GET /facilitator/supported, POST /facilitator/verify, POST /facilitator/settle. Its key lives in an environment variable, never in the code. It settles through the official x402ExactPermit2Proxy, which was not on Atlantic: this project deployed it from the initcode and salt published by coinbase/x402, at the same address as on every other chain.

Pay from your terminal

The client keeps its key in .env or a .private_key file, accepts only Atlantic TEST USDC and refuses any price above 0.01.

git clone https://github.com/juhzinho/pharos-x402-paywall && cd pharos-x402-paywall && npm install
node scripts/keys.js                       # writes .env with fresh test keys, prints only addresses
npm run client -- pay /api/pacific/gas --base https://pharos-x402-paywall.vercel.app
npm run client -- reject --base …          # underpaid, wrong payTo, forged, replay → 402
npm run fork                               # the whole flow on an Atlantic fork, no funds needed
